XV2 SAVE EDITOR — 1.0.0 RC13
=============================

RC13 FEATURES AND FIXES
- Added a dedicated per-CaC Play Data editor using the verified 208-byte record.
- Added training, Time Rift/base activity, play trends, Shenron wishes, and
  Expert Mission statistics.
- Added named searchable mentor, training class, character, and skill fields
  while preserving unknown/modded IDs.
- Added Player, Ranked, and Endless match/win/loss records, including Endless
  Losses and synchronized aggregate Online Wins.
- Added calculated Online Battles, Online Losses, and Win Rate summaries.
- Added selected-CaC and all-CaC load-time snapshot reverts.
- Added Play Data changes to the pre-save summary.
- Rebuilt the page into a responsive two-column layout with a full-width online
  record section and fixed final-row alignment.

RC12 FIX
- Added verified support for legacy compact .excac exports that store their
  character data in a Base64 Data block.
- Compact imports preserve the destination slot's progression prefix and DLC
  block instead of guessing or overwriting unsupported data.
- Japanese and other Unicode CaC names remain fully supported.

RC11 FEATURES AND FIXES
- Expanded Completionist and Everything Verified Max-Out packages with clothes,
  Accessories, Super Souls, Mix Items, Capsules, Festival presets, and a perfect
  all +5 QQ Bang.
- Added verified regular/DLC mentor customization record initialization.
- Giving Customization Keys now initializes missing partner records for occupied CaCs.
- Added Unlock + initialize all to Mentor Customisation while preserving existing records.
- Activated the verified regular, DLC, and Festival customization-option bitfields.
- Confirmed the reported save corruption was a mismatched Steam ownership ID; the
  compared current save and backups were structurally healthy and byte-identical.

RC10 FIX
- Replaced the old generic Black Eyes action with verified male and female variants.
- Male Black Eyes applies Eyes 104 and Forehead 50.
- Female Black Eyes applies Eyes 167 and Forehead 74.

RC9 FIX
- Improved .excac compatibility for Japanese and other Unicode-named CaCs.
- Recognizes verified Base/DLC blocks across harmless casing, namespace, and wrapper variations.
- Retains strict block-length validation before importing character data.
