# XV2 Save Editor 1.0.0 RC13

RC13 adds the verified Play Data editor and completes its layout polish.

## Highlights

- Added a dedicated Play Data tab with verified per-CaC fields.
- Added readable mentor, training class, character, and skill names while preserving unknown or modded IDs.
- Added Player, Ranked, and Endless online records, including Endless losses.
- Added calculated online battle, win, loss, and win-rate summaries.
- Added load-time snapshot reversion for the selected CaC or all Play Data.
- Improved Play Data spacing, grouping, and row alignment.
- Preserved the existing CaC, preset, inventory, QQ Bang, progression, mentor, quest, backup, and platform tools.

## Installation

1. Download `XV2SaveEditor-1.0.0-RC13-Portable.zip` below.
2. Extract the complete ZIP to a normal folder.
3. Run `START XV2 SAVE EDITOR.cmd`.

Do not run the editor from inside the ZIP. Keep an untouched copy of your save until the edited save has been tested in game.
